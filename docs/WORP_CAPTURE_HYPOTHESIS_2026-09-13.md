# WoRP Capture Hypothesis — lineup realization by position

Status: RESEARCH HYPOTHESIS

## Core definition

Captured WoRP = WoRP produced by a player while that player is actually in the fantasy lineup.

If the player produces WoRP on the bench, that WoRP is not captured.

Legal lineup eligibility is only a structural precondition. It is not capture by itself.

## Positional intuition to test

### QB

In 1QB, a backup QB behind an auto-start elite QB is usually structurally blocked from capture except for bye/injury/replacement decisions.

In Superflex / QB-eligible formats, the second QB can be part of the normal starting lineup, so backup/depth QB has a much clearer route to captured WoRP. The relevant question is not simply whether QB depth exists, but whether the format creates a second legally and economically meaningful QB starting path.

### RB

RB backup value may be easier to capture because role changes are often discrete and legible week to week.

Example intuition: Ashton Jeanty starts; Mike Washington is the backup. When Jeanty is active, Washington is benched. If Jeanty is out and Washington inherits major volume, Washington can jump from a deep-RB profile (for example RB60-ish) to a startable RB20-ish weekly role. That situational rank jump is often easier to identify before lineup lock than a comparable weekly WR jump.

Hypothesis: RB depth can have relatively high lineup-capture efficiency because injury/role transitions create clearer ex-ante start signals.

### TE

A backup TE behind an elite auto-start TE can be strongly blocked in ordinary formats unless FLEX eligibility, bye or injury creates a second path into the lineup.

### WR — primary open hypothesis

WR is expected to be the hardest position for lineup capture because multiple similarly valued WRs can remain active simultaneously without a discrete role-transfer event that clearly identifies the correct weekly starter.

Suggested test:

1. Build historical WR tiers / rank bands.
2. For each player-week, compare actual/startable status against the Oracle lineup.
3. Measure how often players from each WR tier beat the lineup threshold / appear in the Oracle optimal lineup.
4. Example target question: if a WR20-level player is Oracle-startable in roughly 15 weeks, how does that frequency change across WR tiers?
5. Use those frequencies to understand where additional rostered WR depth remains reliably lineup-capturable versus where it becomes increasingly ambiguous / bench-prone.

Important: Oracle here is used only to establish ex-post lineup-worthiness frequency. It does NOT prove that a manager could identify the player ex ante.

## Research distinction

Two separate questions must remain distinct:

1. Ex-post lineup worthiness: how often did a player/tier deserve to be in the optimal lineup?
2. Ex-ante lineup identifiability: how often could a manager reasonably know to start that player before the games?

The proposed WR tier-frequency analysis starts with question 1. Any claim about decision difficulty or predictable capture requires a later ex-ante layer.

## Product implication if validated

The WoRP Lab could eventually distinguish positional depth not only by economic value, but also by how readily that value can be realized in the starting lineup.

Do not yet publish this as a frontend conclusion. It remains a hypothesis to test.
